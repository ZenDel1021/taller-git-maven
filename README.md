# Taller: Git y GitHub - Parte 1

**Autor:** Kevin Delgado
**Propósito:** Taller práctico para aprender el uso básico de Git localmente y su integración con GitHub mediante un proyecto Java con Maven.

## Requisitos
- JDK 17
- Maven 3

## Instrucciones de ejecución
1. **Para compilar el proyecto:**
   `mvn clean package`
2. **Para ejecutar el programa:**
   `mvn exec:java` (o ejecútalo directamente desde IntelliJ en `src/main/java/Main.java`).

## Comandos Git practicados
- `git init`
- `git add`
- `git commit`
- `git status`
- `git branch`
- `git push`
- `git pull`
